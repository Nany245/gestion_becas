# Aplicación de Gestión de Becas Nacionales e Internacionales

## Descripción
Plataforma web que permite a los estudiantes buscar, comparar y orientar a estudiantessobre becas nacionales e internacionales.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Python
- SQL Server

## Funcionalidades principales
- Búsqueda de becas por país y tipo.
- Catálogo de universidades.
- Registro e inicio de sesión.
- Gestión de perfil del usuario.
- Recomendaciones personalizadas.
- Seguimiento de aplicaciones.

## Instalación
1. Clonar el repositorio.
2. Instalar dependencias:
   pip install -r requirements.txt
3. Configurar la base de datos en SQL Server.
4. Ejecutar la aplicación:
   python app.py

## Estructura del proyecto
Contiene frontend, backend y base de datos organizados por módulos.
